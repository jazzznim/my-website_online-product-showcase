# Lumière Beauty — Online Product Showcase

A responsive cosmetics showcase website made with **HTML5 and CSS3 only**. It follows the activity requirements: no JavaScript, no JavaScript libraries, and no frameworks.

## Website concept
**Online Product Showcase (Cosmetics)** — presents sample makeup, lip products, and skincare items in a catalog-style layout.

## Folder structure
```text
online-product-showcase/
├── index.html
├── about.html

├── css/
│   └── style.css
├── images/
│   └── image-files/
│       └── README.txt
└── README.md
```

## How to view
1. Download and extract the ZIP file.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the Home, About, and Products pages.

## How to publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders while keeping the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Copy the public website link for submission.

## Notes
- Product names, descriptions, prices, and contact information are sample details for a school activity.
- Product photos are loaded from Unsplash through internet image links, so an internet connection is needed to display them.
- The sample contact email is not a real store contact.
- This is a showcase only; it does not accept orders or payments.
